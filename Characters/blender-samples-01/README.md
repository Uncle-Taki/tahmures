# Blender character samples

This directory contains transparent PNG reference samples extracted from the
retired Godot animation prototypes for Blender scene preparation. It contains
art samples only; Godot project files, generated import metadata, scenes,
scripts, renders, and caches were intentionally excluded.

## Samples

- `characters/tahmures-approved-head/` — reusable approved Tahmures head layers
  from `Characters/godot-character-library-recovery-01/assets/approved-head/`.
- `characters/chapter-01-standins/` — Chapter 01 stand-in character and prop
  samples from the retired prototype's `assets/standins/` directory.

The canonical recovery character library remains at
`Characters/godot-character-library-recovery-01/`; this folder is a compact
Blender-facing sample set. Story scripts and story-related source files are
outside this cleanup and were not changed.
