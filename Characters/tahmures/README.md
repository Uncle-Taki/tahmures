# Tahmures character workspace

This directory stores source artwork, rejected/intermediate versions, and the
durable media implementation workflow. It is not gitignored. Files are local
and uncommitted until the owner explicitly authorizes a commit.

The imported `tahmures_sprites_layout01_v2.zip` and accompanying loose PNGs and
report are preserved unchanged. The exact ZIP contents are also available in
`versions/layout01-v2/` for inspection. That version's **editable puppet is
rejected**; its exact source-pose preview is not production evidence.

The current task uses `versions/layout01-v2/source/approved_master.png` as the
approved visual reference, on the authority of the owner's 2026-10-08 task.
This does not approve v2's extracted sprites or a future repaired puppet. The
source is immutable and its checksum is recorded in the workflow.

Start with [the workflow](workflow/README.md) and its single
[phase-status record](workflow/phase-status.json). No candidate output is
currently approved. The workflow points to the existing continuity bible and
blueprints; it does not establish a second story/cast authority.
