# Receiving near-final independent review

Codex owns architecture, implementation and validation. Claude checks the
complete phase near the end in a fresh session; it does not repair the assets.
Historical GLM receipt instructions do not control current role routing.

1. Read the actual saved report and verify its package hashes against the
   current submitted candidate. Preserve the report and append a history event.
2. Confirm actual image access and independent review: a session that implemented
   the artwork must not certify its own work. A viewer limitation keeps the
   independent gate open but does not establish an artwork defect.
3. For concrete blocking findings, Codex performs the bounded correction in a
   new version and verifies actual artifacts. Keep accepted work unchanged;
   prepare one focused closure check when complete, not a review every iteration.
4. For actual independent acceptance, record the exact report/hash evidence;
   then obtain explicit human visual approval of the same candidate before
   freezing/releasing it. Machine and Claude checks cannot supply that approval.
5. Run the next Codex task only once its declared release conditions pass.
   Preserve source/provenance and scopes; no paid calls, publication, commits or
   pushes without separate owner authorization.
