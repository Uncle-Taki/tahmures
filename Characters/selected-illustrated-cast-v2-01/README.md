Their cream inner garments end around the knees so the trousers are visible. The long blue/gold and green outer coats remain. Faces, hair, horns, body type, palette, pose and original shoes were requested unchanged and checked visually. These edits apply **only to this V2 branch**; Paper Puppet images are unchanged.

The edits were produced with built-in image_gen using each actual V2 image as the edit target and Garshasp only as trouser reference. The output is a newly generated garment derivative, not a pixel-exact patch; small incidental differences may remain. Both new garments await owner review. The other five cast images are unchanged byte copies. No new Garshasp cast member or courier is added.
