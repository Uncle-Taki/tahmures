# Part I — Language, Intent, and Reliable Instructions

Tahmures begins with a deceptively simple belief: if a command fails, the
solution is to make it longer. Six incidents overturn that belief.

Part I teaches you to:

- Treat a prompt as an interface, not an incantation
- Separate fluency from evidence
- Define success before optimising wording
- Structure task, context, constraints, and output
- Resolve authority outside the model
- Select and evaluate examples systematically

The chapters are designed to be read in order, but each includes its own
prerequisites and a standalone engineering problem.
