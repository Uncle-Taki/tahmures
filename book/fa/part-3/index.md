# بخش سه — Context، حافظه، ابزارها و Agentها

بخش سوم تهمورث را از آزمایشگری دقیق به طراح سامانه تبدیل می‌کند. او می‌آموزد
که context باید انتخاب و ردیابی شود، retrieval به‌تنهایی شاهد معتبر نمی‌سازد،
memory به چرخهٔ عمر نیاز دارد، tool باید کمترین اختیار را داشته باشد، agent
باید توقف‌پذیر باشد و hand-off باید هدف و محدودیت‌ها را سالم منتقل کند.

جهان‌شمول دربارهٔ همهٔ provider‌ها نیستند.
