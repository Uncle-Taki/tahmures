# Tahmures Character Review Checklist

## Source integrity
- [ ] Correct approved specification opened.
- [ ] Correct approved master image opened.
- [ ] Reference conflicts checked.
- [ ] Candidate/rejected references excluded.
- [ ] Original source files preserved.

## 2D design
- [ ] Silhouette reads at thumbnail size.
- [ ] Front, side and back views agree.
- [ ] Proportions match approved source.
- [ ] Face and key features match.
- [ ] Costume layers and attachments are coherent.
- [ ] Palette is source-backed.
- [ ] Proposals are clearly distinguished from approved facts.

## Blender scene
- [ ] Blender version recorded (target: 5.3 unless project says otherwise).
- [ ] Working copy / new collection used.
- [ ] Naming, axes, units and origins follow repository rules.
- [ ] Primary masses and silhouette reviewed before details.
- [ ] Front, side, back and three-quarter views captured.
- [ ] No unapproved geometry or props added.
- [ ] Scene saves and reopens.

## Mesh and materials
- [ ] Meshes reviewed for accidental duplicates.
- [ ] Normals and topology inspected.
- [ ] Non-manifold geometry reviewed.
- [ ] Materials and image paths verified.
- [ ] Clay/flat and final-material reviews captured.

## Rigging (if required)
- [ ] Deformation zones reviewed.
- [ ] Skin weights checked.
- [ ] Extreme poses checked.
- [ ] Rigid costume elements tested.

## Delivery
- [ ] Output files listed.
- [ ] Source and derivative assets distinguished.
- [ ] Provenance and license recorded.
- [ ] Export validated for intended target.
- [ ] Unverified checks and known limitations reported.
