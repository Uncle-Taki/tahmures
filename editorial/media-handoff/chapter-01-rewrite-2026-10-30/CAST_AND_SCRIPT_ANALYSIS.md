# Cast and screenplay analysis

## Dramatic pass

The dramatic question is whether a ruler can distinguish a found command from the task he actually wants done before uncertainty becomes a public alarm. The learning is earned through choices: Chapar reports a discovery; Tahmures declines to specify the task; the divs choose three different reasonable interpretations; a delivered tablet is mistaken for a current commission; gate closure and riders create a market rumour. The royal request and handoff own the failure, rather than a simple tale of foolish or evil divs.

Shahrasp's early clarifying question makes the ignored alternative visible. The king's later admission is specific. An interim message limits confrontation before the lengthy lesson. The full correction requests both acknowledgement and outcome. Reopened trade does not restore every lost customer. Simurgh supplies discriminating questions, not missing historical knowledge. This gives the ending a result and a remaining uncertainty.

Persian was edited first, then English paired by stable action/utterance IDs. Different syntax serves the same acting intention; uncertainty, negation, authority, the sunrise deadline, eleven kilns and object custody match. The long educational explanation is a separate modern narrator interlude. It must receive readable local graphics and its own measured pacing, rather than forcing technical words into ancient dialogue or an eight-second clip.

| Simurgh | Long neck, long legs, long straight beak | Large rounded head, crest and short curved beak |
| Alpha | Nine opaque RGB portraits | Tahmures true RGBA; six opaque portraits |
| Source scope | Two original selected master copies plus new owner-supplied Chapar/Arash portraits; five portrait derivatives need likeness review | Five unchanged supplied copies; two garment derivatives need review |

The images were visually inspected together, not judged from filenames alone. Contact sheets are technical local review derivatives, not uploadable identity masters. Flat portraits do not supply separated puppet layers, turnarounds, lip shapes or invisible limbs. V2's single alpha image does not establish transparent generated video. The supplied grey backgrounds are reference backdrops, not palace sets.

For Paper Puppet, favour restrained planar holds and deliberate silhouette changes; use discrete composited phases for difficult transfers. For V2, retain the rounded facial volumes in 2D without plastic shading or morphing clothing. Both need the same narrative coverage. There is no basis for claiming one will generate more consistently until a controlled pilot is actually reviewed.

## Missing visual work

The original selected collections each contained seven portraits. The current Paper Puppet handoff now adds the owner-supplied Chapar nomad and Arash armored archer as byte-identical copies; it has nine principal references. Illustrated V2 still lacks those two images. All nine now have character-information cards in each branch; V2 marks the two unsupplied references missing. Matching palace/Divan House/river/fortress/market sets, tablet/seal/cloth, mounted views, guards, merchants, riders, charcoal workers, judge/apprentice vignettes and exact start frames are not supplied by either selected collection. Existing older painted sets are not automatically compatible with either new branch. Do not fill gaps by importing another character's identity.

Recommended first moving-picture pilot: the seated Tahmures/Shahrasp listening phase in RW01-S11-SH01, after a branch-matching table/prop/start-frame review. Both identities exist; the shot tests scale, face/clothing stability and tablet custody with restrained movement. Start silent with fixed mouths, not the whole long corrective speech. Then test dialogue after separately approved performances and measured timing. This is a proposed pilot, not an executed generation.
