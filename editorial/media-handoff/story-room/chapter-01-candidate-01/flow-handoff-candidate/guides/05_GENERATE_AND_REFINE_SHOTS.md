[Video controls](https://support.google.com/flow/answer/16353334?hl=en); [model compatibility](https://support.google.com/flow/answer/16352836?hl=en); [editing](https://support.google.com/flow/answer/16935718?hl=en). 1. Open S01_SH01. With its approved wide image, choose model selector → **Video → Frames**; put it in **Add start frame**. No end frame has been approved. Paste only the card's ambient pilot prompt.
2. Select Omni Flash 1.1 / 360p draft if offered, landscape, the card's generation duration and **one output**. Record displayed credits and request owner's finite spending decision. Do not generate on an unchecked model fallback. Only then click **Generate**.
3. Watch the entire returned candidate normally and slowly. Use SHOT_REVIEW_CHECKLIST; compare first/last frames with the original. Dust/light is the only pilot motion; crystal/hands/face stay still. Log defects and actual credits. Reject drift before making more scenes.
4. For a reference-based shot, select **Video → Ingredients** instead and attach approved references/registered @ names. This supplies reusable references, not the exact same control as a start/end frame. Do not combine controls unless supported by the selected mode.
5. For later repairs, Omni's video edit route permits a selected segment; use generation settings → Video → Omni Flash, select the candidate and an up-to-10-second edit region, then request one correction. Review the new take, retaining the original.
6. Veo extensions are a separate path: open an eligible Veo clip → **Extend**; use Lite under the documented restrictions. Do not assume Fast/Quality/Omni can extend themselves.
