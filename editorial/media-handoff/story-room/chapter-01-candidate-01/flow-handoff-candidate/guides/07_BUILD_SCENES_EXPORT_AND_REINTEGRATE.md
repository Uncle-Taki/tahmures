# 07 — Scene review and local reintegration

[Scene/frame controls](https://support.google.com/flow/answer/16935718?hl=en); [downloads](https://support.google.com/flow/answer/16935308?hl=en).

1. For a reviewed candidate, hover its tile → **More → Add to Scene**. Open the scene; drag clips into planned order and trim with handles. Preview the whole sequence. Keep eleven narrative scene groups plus the title separately identified; do not adopt the old board clock.
2. To reuse a boundary image later, open video, pause, hover and choose **Save frame**. It is a NEW candidate reference, not automatic approval. Review the exact saved still and its provenance before making it a next start/end frame.
3. Preserve older edits through History; use **Save to Project** if an older version is needed in Scenebuilder. Never overwrite rejected take records.
4. Download the scene or individual take. For a tile use **More → Download** and the offered video format. Verify the real local file opens; do not rename a GIF into MP4. Rename a COPY to the shot's final_filename, retaining original download and metadata.
5. Put new files in a new local revision, e.g. `flow-returns/E01/S01/SH01/r01/take01/`, outside approved source folders. Record actual Flow asset identifier/link if available, prompt/settings/date/reference hashes/credit spend, local SHA-256 and review status. No automatic GitHub sync exists.
6. Follow ASSEMBLY_PLAN in a duplicate local edit. Keep original audio/subtitles; trim picture to exclusive frame intervals. Export a new candidate and inspect actual streams/frames, then watch/listen fully.

Scene UI is a convenience; do not assume it exports every audio/subtitle/edit decision reproducibly.
